## 功能模块

### 1. 认证系统

**登录流程:**
1. 访问 `/login`
2. 选择 OAuth2 提供商（GitHub/Google）
3. 跳转到提供商授权页面
4. 授权后回调到 `/api/auth/callback`
5. 后端验证并创建会话
6. 重定向到首页

**退出登录:**
1. 点击右上角用户头像
2. 选择"退出登录"
3. 调用 `/api/auth/logout`
4. 清除会话 Cookie
5. 重定向到 `/login`

### 2. 初始化向导

**步骤 1: 欢迎页面**
- 产品介绍
- 使用条款确认

**步骤 2: 数据库配置**
- 选择数据库类型（SQLite/MySQL/PostgreSQL）
- 配置连接信息
- 测试连接

**步骤 3: OAuth2 配置**
- 选择提供商（GitHub/Google/GitLab）
- 输入 Client ID/Secret
- 配置回调 URL

**步骤 4: 完成**
- 保存配置
- 创建管理员账号
- 进入系统

### 3. 个人中心

**用户菜单功能:**
- 显示用户信息（头像、姓名、邮箱）
- 个人资料设置
- 系统设置入口
- 退出登录

**位置:** AppBar 右上角

## 路由守卫

### 认证检查

```typescript
// 伪代码
const ProtectedRoute = ({ children }) => {
  const { isAuthenticated } = useAuth();
  
  if (!isAuthenticated) {
    return <Navigate to="/login" />;
  }
  
  return children;
};
```

### 初始化检查

```typescript
// 伪代码
const SetupRequired = ({ children }) => {
  const { isSetupCompleted } = useSetup();
  
  if (!isSetupCompleted) {
    return <Navigate to="/setup" />;
  }
  
  return children;
};
```

## 用户故事

### 故事 1: 新用户首次使用

> 作为新用户，我希望通过初始化向导快速配置系统，以便开始使用。

**验收标准:**
- [ ] 首次访问自动跳转到 `/setup`
- [ ] 分步引导清晰易懂
- [ ] 数据库配置简单
- [ ] OAuth2 配置有详细说明
- [ ] 完成后自动进入系统

### 故事 2: 用户登录

> 作为已注册用户，我希望通过 OAuth2 快速登录，以便访问系统。

**验收标准:**
- [ ] 未登录访问保护页面跳转到 `/login`
- [ ] 支持 GitHub/Google 登录
- [ ] 登录后自动回到原页面
- [ ] 登录状态持久化

### 故事 3: 用户退出

> 作为用户，我希望安全退出登录，以便保护账户安全。

**验收标准:**
- [ ] 右上角显示用户菜单
- [ ] 点击"退出登录"清除会话
- [ ] 退出后重定向到登录页
- [ ] 无法通过后退按钮访问保护页面

## 安全考虑

### 认证安全

- OAuth2 状态参数验证（防 CSRF）
- JWT Token 签名验证
- Token 过期自动刷新
- 安全的 Cookie 设置（HttpOnly, Secure, SameSite）

### 授权安全

- 后端 RBAC 权限校验
- K8s RBAC 同步
- API 级别权限控制
- 审计日志记录

### 数据安全

- 敏感配置加密存储
- HTTPS 强制（生产环境）
- 输入验证和过滤
- SQL 注入防护
